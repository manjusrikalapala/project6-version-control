# Project 6: Version Control Infrastructure

## Overview

Version control is a critical practice in modern DevOps and Infrastructure as Code (IaC). This project demonstrates how Git and GitHub can be used to manage, track, and review changes made to Terraform infrastructure code through a structured branching and Pull Request workflow.

## Objective

The primary objective of this project is to implement version control for Terraform code using Git and GitHub while following industry-standard collaboration practices such as branching, committing, and creating Pull Requests.

## Technologies Used

- Git
- GitHub
- Terraform
- Linux

## Project Activities

- Created and configured a local Git repository
- Added Terraform infrastructure files to version control
- Connected the local repository to GitHub
- Pushed code to a remote repository
- Created a dedicated feature branch for changes
- Updated project documentation
- Committed and pushed changes from the feature branch
- Created a Pull Request to review and merge changes

## Git Workflow Implemented

```text
Main Branch
    │
    ├── Initial Commit
    │
    └── Feature Branch
            │
            ├── Documentation Update
            │
            └── Pull Request
                    │
                    └── Merge to Main
```

## Key Learning Outcomes

- Understanding Version Control concepts
- Managing Infrastructure as Code using Git
- Working with branches and commits
- Tracking infrastructure changes effectively
- Using GitHub for repository management
- Implementing Pull Request workflows
- Following DevOps best practices for collaboration

## Deliverables

- GitHub Repository
- Feature Branch
- Commit History
- Pull Request (PR) Link

## Conclusion

This project successfully demonstrates the use of Git and GitHub for version control of Terraform infrastructure code. By implementing a feature branch workflow and creating a Pull Request, the project highlights industry-standard practices used by DevOps and Cloud Engineering teams to manage infrastructure changes in a controlled and collaborative manner.
